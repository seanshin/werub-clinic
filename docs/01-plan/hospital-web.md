# Hospital Web 기획서

> Created: 2026-05-06
> Status: In Progress

## 개요

병원/의원 전용 웹 서비스. 기존 커뮤니티(example.org) · 엔터프라이즈(work.example.org)에 이어 세 번째 서비스로 추가.
동네 의원부터 종합병원까지 지원.

## 서비스 정보

| 항목 | 값 |
|------|-----|
| 도메인 | clinic.example.org |
| 포트 | :3600 |
| 패키지 | packages/hospital-web |
| 브랜딩 | WeRU.B Clinic |
| 테마 컬러 | Emerald (의료 그린) |
| cafeType | `hospital` (종합병원) / `clinic` (의원/병원) |

## 아키텍처

```
병원웹(:3600) → rewrite → 메인앱(:3000)/api/* → DB
                          → Auth Server(:4000)
```

- enterprise-web과 동일한 프록시 패턴
- 자체 API 없음 — 메인 앱 API 100% 프록시
- 독립 빌드/배포

## 페이지 구성

### Phase 1 (이번 작업)
| 경로 | 페이지 | 설명 |
|------|--------|------|
| `/` | 랜딩 | 병원용 기능 소개, 요금제, 도입 문의 |
| `/login` | 로그인 | 이메일+비밀번호, 병원 코드 입력 |
| `/register` | 등록 | 신규 병원 등록 + 회원가입 (5단계) |
| `/dashboard` | 대시보드 | 병원 허브 — 요약 카드, 공지, 캘린더, 바로가기 |
| `/profile` | 프로필 | 사용자 정보, 로그아웃 |
| `/notifications` | 알림 | 미읽음 알림 |

### Phase 2 (별도 진행 — 병원 전용 기능 연결)
- 진료 예약/접수 관리
- 환자 차트/기록
- 의료진 근무표 (당직/교대)
- 처방/투약 관리
- 보험 청구
- 의료 물품 관리

### 기존 기능 재활용
- 전자결재 (W.Sign) — 의료 문서 승인/결재
- 실시간 채널 — 의료진 소통
- 캘린더 — 진료 일정, 수술 일정, 당직
- Wiki (ShareSpace) — 진료 매뉴얼, 프로토콜
- 근태 관리 — 교대 근무
- AI Knowledge — 의료 지식 베이스

## cafeType 확장

현재: `cafe` | `company` | `organization`
추가: `hospital` | `clinic`

- `hospital`: 종합병원 (진료과 다수, 병동, 응급실)
- `clinic`: 의원/병원 (1~3 진료과, 외래 중심)

## 등록 플로우

1. 모드 선택: 새 병원 등록 / 병원 코드로 합류
2. 계정 생성 (회원가입 또는 로그인)
3. 병원 정보 입력 (병원명, 사업자등록번호, 대표원장, 진료과, 규모)
4. 기능 설정 (기본 ON: 채널/캘린더/Wiki/근태, 선택: 전자결재/OKR)
5. 완료 — 병원 코드 발급

## 업종 분류

의원/병원 전문과목:
- 내과, 외과, 정형외과, 피부과, 이비인후과, 안과, 치과
- 산부인과, 소아청소년과, 비뇨기과, 신경외과, 신경과
- 정신건강의학과, 재활의학과, 마취통증의학과
- 가정의학과, 응급의학과, 영상의학과, 진단검사의학과
- 한의원, 한방병원
- 종합병원, 상급종합병원

## 배포

- PM2 프로세스: `werub-hospital`
- Nginx: `clinic.example.org` → `:3600`
- 배포 스크립트: `scripts/deploy-hospital.sh`
- 독립 빌드/배포 (메인앱 무영향)

## 기술 스택

- Next.js 16 (독립 패키지)
- Tailwind CSS v4
- 메인 앱 API 프록시 (next.config.mjs rewrites)
- efetch() API 래퍼 (CSRF + 401 인터셉터)
